发运单生成器

导入 ERP 多级 BOM → 在树上维护发运配置 → 自动计算聚合 → 导出发运单。
本说明只讲怎么用，按"快速上手 → 功能详解 → 速查表"组织。

01 🚀 快速上手（四步出单）
01
📂 导入 BOM
选择 ERP 导出的 Excel/CSV，自动清洗并建成树
02
🌲 维护发运配置
在左侧树上把需要单独发运的节点设为 否 并指定发运主体、方式
03
🔢 计算 / 👁️ 预览
自动递归算数量、三重聚合，右侧出预览表
04
📊 导出
导出 Excel / CSV，选保存位置，得到格式化发运单
💡 中途随时 💾 保存 进度，下次 📂 加载 继续；做错了 ↩️ 撤销。

03 ⚙️ 发运配置怎么设
🎯 核心概念：什么是"发运单元"

一个节点成为发运单元（进入发运单统计），需同时满足以下条件：

📋
是否展开 = 否
标记为不再向下展开
🏢
发运主体 ≠ 空
如 01-机头、98-捆装发运类
🚚
发运方式 ≠ 空
A-散装 / B-打捆 / C-装箱 / D-特殊
🔧 三种设置入口
🖱️
单击单元格
直接单击树上的「是否展开 / 发运主体 / 发运方式」列，弹出选择菜单。
📌
右键菜单
右键节点 → 设置是否展开 / 设置发运主体 / 设置发运方式 / 详细配置…
✏️
双击编辑备注
双击「备注」列直接在格内输入。
⚡ 自动规则（省事）
→ 发运主体选 98-捆装发运类 → 自动配 B-打捆
→ 发运主体选 99-整合装箱类 → 自动配 C-装箱
→ 给"是否展开=是"的节点配上发运主体 → 自动改为"否"（成为发运单元）
🔗 联动与确认
⚠ 把节点设为 "是"（展开）会清空它已有的发运配置（会弹确认）。
⚠ 把节点设为 "否" 时，若它的子节点已配发运信息，会提示是否一并清除。
✓ 勾选子节点会自动取消其祖先节点的勾选（避免重复统计）。
04 📋 批量与快捷操作
☑️ 勾选节点

点每行最左侧的 ☑（支持 Shift 范围勾选、Ctrl 单选）。

📋 批量设置 F1

对已勾选节点一次性设置 是否展开 / 发运主体 / 方式 / 备注。
⚠️ 仅支持勾选同一层级且同父物料的节点（兄弟节点）； 跨层级 / 跨父勾选会被拦截提示，防止把父节点设为"否"导致其下内容被折叠隐藏。

🖌️ 格式刷

右键某节点 📋 复制格式 → 勾选目标节点 → 📋 粘贴格式到勾选节点
快捷键：Ctrl+Shift+C / Ctrl+Shift+V

07 💾 撤销、进度与防丢失
↩️ 撤销 / 恢复

↩️ / ↪️ 按钮或 Ctrl+Z / Ctrl+Y，最多保留 30 步。
设置发运配置、批量操作、添加/拆分/删除物料、格式刷等都可撤销。

💾 保存进度

Ctrl+S 把当前树和配置存成 Excel 进度文件；📂 加载 可恢复继续。

🔔 未保存提醒

有改动未保存时，标题栏显示 *未保存；此时关窗会弹出"保存 / 不保存 / 取消"。

💡 导入新 BOM / 加载进度会开启新数据集，撤销栈自动清空（不会把旧数据撤销回来）。
08 📊 计算与导出
🔢 最终数量

子节点最终数量 = 自身用量 × 父节点最终数量（顶级节点数量为 1，逐级连乘）。

🔄 三重聚合

按 物料号 + 发运主体 + 发运方式 + 备注 合并求和——同一物料在不同父节点下，只要发运配置相同，数量自动汇总。

⚖️ 总重

按各行 数量 × 净重 逐行求和。

09 ❓ 常见问题
Q 导入后某些节点没进发运单？ ▼
只有"是否展开=否 且 配齐发运主体+方式"的绿色节点才进发运单。检查该节点是否为展开节点（白色）或边界节点（浅黄、未配齐）。
Q 想让某个物料单独发运？ ▼
把它的"是否展开"设为"否"，再指定发运主体和发运方式即可（选 98/99 会自动配方式）。
Q 一个物料要拆成两批发运？ ▼
右键该节点 → ✂️ 拆分物料，分别输入数量、发运主体和方式。
Q CSV 导入报错或乱码？ ▼
程序已自动尝试 UTF-8 / GBK / GB18030 编码。仍失败请确认文件确为 ERP 导出的 BOM 文件，且含"子物料号、父物料号、数量、子物料净重"等必需列。
Q 发运主体名称想自定义？ ▼
点工具栏 🏷️ 发运主体，在定义窗口增删改名称，或用预设管理（保存为预设 / 新建 / 置为当前）。
