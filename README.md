# 发运单生成器（桌面版）

## 项目简介

发运单生成器是一款离线桌面应用，用于解决ERP系统中多级BOM数据的发运单生成问题。

### 核心功能

- **数据导入**：支持导入Excel/CSV格式的多级BOM数据
- **树结构显示**：将平面数据转换为可视化树结构
- **发运配置**：在树节点上配置发运主体、发运方式等信息
- **自动计算**：递归计算最终数量，三重聚合
- **数据导出**：导出格式化的Excel发运单

### 解决的问题

1. 同一物料号在不同发运方式下的数量拆分
2. 同一物料号在不同发运主体下的分开显示
3. 打捆件内部子件的边界处理
4. 递归计算所有物料的最终数量
5. 同一子物料在不同父物料下可有不同的发运配置

## 快速开始

### 环境要求

- Python 3.9 或更高版本
- Windows 10/11 操作系统

### 安装依赖

```bash
# 克隆项目
git clone <repository_url>
cd 发运单生成器

# 安装依赖
pip install -r requirements.txt
```

### 运行程序

```bash
python main.py
```

### 打包成EXE

```bash

# pyinstaller --name="发运单生成器" --windowed --onefile main.py
```

## 使用说明

### 1. 导入BOM数据

1. 点击工具栏的"导入BOM数据"按钮
2. 选择从ERP导出的Excel或CSV文件
3. 系统自动清洗和映射字段
4. 树结构自动显示

### 2. 维护发运配置

1. 在树结构中双击节点
2. 在弹出的对话框中设置：
   - 是否展开
   - 发运主体
   - 发运方式
   - 备注
3. 点击"确定"保存配置

### 3. 计算发运单

1. 配置完成后，点击"计算"按钮
2. 系统自动计算最终数量和聚合
3. 右侧表格显示计算结果

### 4. 导出发运单

1. 点击"导出发运单"按钮
2. 选择保存位置和文件格式
3. 生成格式化的发运单文件

## 核心算法

### 最终数量计算

```
最终数量 = 该物料自身用量 × 所有上级用量的连乘

递归公式：
  顶级节点：最终数量 = 自身数量
  子节点：最终数量 = 自身数量 × 父节点最终数量
```

### 三重聚合

```
聚合维度：物料号 + 发运主体 + 发运方式 + 备注

总数量 = SUM(该维度组合下所有物料的最终数量)
总重 = 总数量 × 净重
```

### 分组排序

```
分组排序：
  - 01-20：1（物理分组）
  - 98：2（打捆发运）
  - 90-91：3（增供/液压）
  - 99：4（整合装箱）
  - 00：5（特殊）

组内排序：
  - B：1（打捆）
  - A：2（散装）
  - C：3（装箱）
  - D：4（特殊）
```

## 常见问题

### Q1: 导入数据后树结构显示不正确？

A: 请检查原始数据是否包含"层号"和"父物料号"字段，系统需要这些字段来构建树结构。

### Q2: 计算结果数量为0？

A: 请检查是否为叶子节点（没有子节点的节点）配置了发运信息。只有配置了发运信息的节点才会参与计算。

### Q3: 导出的Excel文件乱码？

A: 请确保使用UTF-8编码保存文件。系统默认使用UTF-8-BOM编码，兼容性更好。
