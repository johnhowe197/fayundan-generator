# 子智能体验证机制说明

## 概述

本项目添加了子智能体验证机制，用于在每次修改代码后自动检查和验证，确保：
1. 代码语法正确
2. 模块导入正常
3. 核心功能不被破坏
4. 新功能实现正确
5. 符合需求要求

## 文件结构

```
发运单生成器/
├── verify_changes.py          # 基础验证脚本
├── verify_feature.py          # 功能验证脚本
├── pre_commit_verify.py       # 预提交验证脚本（推荐使用）
└── docs/
    └── 子智能体验证机制说明.md  # 本文档
```

## 验证内容

### 1. 语法验证
- 检查所有Python文件的语法正确性
- 确保没有语法错误

### 2. 导入验证
- 检查所有核心模块是否可正常导入
- 验证关键类和方法是否存在

### 3. 核心功能验证
- **BOMNode**: 数据模型创建和属性
- **TreeBuilder**: 树结构构建
- **BOMParser**: BOM数据解析
- **Calculator**: 计算引擎
- **Exporter**: 导出功能

### 4. 功能实现验证
- BOM拆分功能（图号、规格提取）
- 材质和工艺路线过滤
- 是否展开=否时隐藏下级节点
- 列索引一致性

### 5. 回归测试
- 验证所有关键方法存在且可调用
- 确保没有破坏已有功能

## 在Claude Code中使用

作为Claude Code，在修改代码后输出给用户之前，应该：

1. **运行预提交验证**
```python
from pre_commit_verify import pre_commit_check
success = pre_commit_check()
```

2. **根据验证结果决定**
- 如果验证通过：输出代码给用户
- 如果验证失败：先修复问题，然后重新验证

3. **在响应中说明验证结果**
```
✅ 代码验证通过
- 语法检查: X 项通过
- 功能验证: X 项通过
- 回归测试: X 项通过

可以安全使用修改后的代码。
```

## 添加新的验证项

如果需要添加新的验证项，可以修改相应的验证脚本：

1. **verify_changes.py**: 添加基础语法和导入检查
2. **verify_feature.py**: 添加具体功能验证
3. **pre_commit_verify.py**: 添加预提交验证

示例：添加新的功能验证

```python
def verify_new_feature(self):
    """验证新功能"""
    print("\n[验证] 新功能...")

    try:
        # 你的验证代码
        from your_module import YourClass

        # 验证逻辑
        instance = YourClass()
        result = instance.your_method()

        if result == expected_value:
            self.results['features']['passed'].append("新功能正确")
        else:
            self.results['features']['failed'].append("新功能错误")

    except Exception as e:
        self.results['features']['failed'].append(f"新功能异常: {e}")
```

## 注意事项

1. **每次修改代码后**都应该运行验证
2. **验证失败时**必须先修复问题再输出代码
3. **验证通过**不代表完全没有问题，但可以确保基本功能正常
4. **定期更新**验证脚本以覆盖新的功能

## 故障排除

### 问题1：导入错误
```
ModuleNotFoundError: No module named 'xxx'
```
**解决**: 检查模块路径是否正确，确保 `__init__.py` 文件存在

### 问题2：语法错误
```
SyntaxError: invalid syntax
```
**解决**: 检查代码语法，修复语法错误

### 问题3：测试失败
```
AssertionError: 预期值与实际值不符
```
**解决**: 检查功能实现逻辑，修复bug
