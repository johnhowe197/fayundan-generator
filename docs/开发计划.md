### 任务3：树结构构建器

```
目标：将平面BOM数据转换为树结构

输入：DataFrame (平面BOM数据)
输出：BOMNode (根节点)

算法：
1. 遍历所有行，创建BOMNode对象
2. 建立物料号→节点的映射
3. 根据父物料号建立父子关系
4. 从level=0找到根节点

关键点：
- 处理顶级节点（level=0）
- 处理多级父子关系
- 处理循环引用检测
```

### 任务4：计算引擎

```
目标：实现递归计算和聚合

算法：
1. 递归计算最终数量
   - 顶级节点：final_quantity = quantity
   - 子节点：final_quantity = quantity × parent.final_quantity
   
2. 三重聚合
   - 按 物料号+发运主体+发运方式+备注 分组
   - SUM(最终数量)
   - 重新计算总重 = 总数量 × 净重

3. 分组排序
   - 分组排序：01-20=1, 98=2, 90-91=3, 99=4, 00=5
   - 组内排序：B=1, A=2, C=3, D=4
```

## 附录：核心计算公式

### 1. 最终数量计算

```
最终数量 = 该物料自身用量 × 所有上级用量的连乘

递归公式：
  顶级节点：最终数量 = 自身数量
  子节点：最终数量 = 自身数量 × 父节点最终数量

边界规则：
  如果父节点"是否展开=否"，停止向上追溯
```

### 2. 聚合计算

```
聚合维度：物料号 + 发运主体 + 发运方式 + 备注（不含父物料号）

总数量 = SUM(该维度组合下所有物料的最终数量)
总重 = 总数量 × 净重

重要：同一子物料在不同父物料下，只要发运配置相同，数量会自动合并
```

### 3. 辅助计算列

```
聚合键 = CONCAT(物料号, '|', 发运主体, '|', 发运方式, '|', IFNULL(备注, ''))

分组排序 = CASE
  WHEN 发运主体 IN ('01',...,'20') THEN 1
  WHEN 发运主体 = '98' THEN 2
  WHEN 发运主体 IN ('90','91') THEN 3
  WHEN 发运主体 = '99' THEN 4
  WHEN 发运主体 = '00' THEN 5
END

组内排序 = CASE 发运方式
  WHEN 'B' THEN 1
  WHEN 'A' THEN 2
  WHEN 'C' THEN 3
  WHEN 'D' THEN 4
END
```
