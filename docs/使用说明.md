# 发运单生成器 · 使用说明

> 离线桌面工具：导入 ERP 多级 BOM → 在树上维护发运配置 → 自动计算聚合 → 导出发运单。
> 本说明只讲**怎么用**，按"快速上手 → 功能详解 → 速查表"组织。

---

## 一、快速上手（四步出单）

| 步骤 | 操作 | 说明 |
|:--:|------|------|
| **1** | 点工具栏 **📂 导入BOM** | 选择 ERP 导出的 Excel/CSV，自动清洗并建成树 |
| **2** | 在左侧树上维护发运配置 | 把需要单独发运的节点设为"否"并指定发运主体、方式 |
| **3** | 点 **🔢 计算**（或 **👁️ 预览**） | 自动递归算数量、三重聚合，右侧出预览表 |
| **4** | 点 **📊 导出Excel** / **📄 导出CSV** | 选保存位置，得到格式化发运单 |

> 💡 中途随时 **💾 保存** 进度，下次 **📂 加载** 继续；做错了 **↩️ 撤销**。

**节点颜色**

| 颜色 | 含义 |
|:--:|------|

| 🟨 浅黄 | **边界节点**：是否展开=否，但发运信息还没配齐 |
| ⬜ 白色 | **展开节点**：是否展开=是，继续向下展开子节点 |

## 三、发运配置怎么设

### 核心概念：什么是"发运单元"

一个节点成为发运单元（进入发运单统计），需同时满足：

- **是否展开 = 否**
- **发运主体** 不为空（如 01-机头、98-捆装发运类）
- **发运方式** 不为空（A-散装 / B-打捆 / C-装箱 / D-特殊）

### 三种设置入口

1. **单击单元格**：直接单击树上的「是否展开 / 发运主体 / 发运方式」列，弹出选择菜单。
2. **右键菜单**：右键节点 → 设置是否展开 / 设置发运主体 / 设置发运方式 / 详细配置…。
3. **双击编辑备注**：双击「备注」列直接在格内输入。

### 自动规则（省事）

- 发运主体选 **98-捆装发运类** → 自动配 **B-打捆**
- 发运主体选 **99-整合装箱类** → 自动配 **C-装箱**
- 给"是否展开=是"的节点配上发运主体 → 自动改为"否"（成为发运单元）

### 联动与确认

- 把节点设为 **"是"**（展开）会**清空**它已有的发运配置（会弹确认）。
- 把节点设为 **"否"** 时，若它的子节点已配发运信息，会提示是否一并清除。
- 勾选子节点会**自动取消**其祖先节点的勾选（避免重复统计）。

## 四、批量与快捷操作

- **勾选节点**：点每行最左侧的 ☑（支持 Shift 范围勾选、Ctrl 单选）。
- **📋 批量设置（F1）**：对已勾选节点一次性设置是否展开/发运主体/方式/备注。
- **格式刷**：右键某节点 **📋 复制格式** → 勾选目标节点 → **📋 粘贴格式到勾选节点**（快捷键 Ctrl+Shift+C / Ctrl+Shift+V）。
- **➕ 添加子物料 / ✂️ 拆分物料 / 删除物料**：右键菜单操作。
- **🏷️ 发运主体**：打开"发运主体定义"窗口，可增删改主体名称、管理预设（输送机发运/转载机发运等）。

## 七、撤销、进度与防丢失

- **撤销/恢复**：↩️/↪️ 按钮或 Ctrl+Z / Ctrl+Y，最多保留 **5 步**。设置发运配置、批量操作、添加/拆分/删除物料、格式刷等**都可撤销**。
- **保存进度**：💾（Ctrl+S）把当前树和配置存成 Excel 进度文件；📂 加载可恢复继续。
- **未保存提醒**：有改动未保存时，标题栏显示 `*未保存`；此时关窗会弹出"保存 / 不保存 / 取消"。
- **导入新 BOM / 加载进度**会开启新数据集，撤销栈自动清空（不会把旧数据撤销回来）。

## 八、计算与导出（了解即可）

- **最终数量**：子节点最终数量 = 自身用量 × 父节点最终数量（顶级节点数量为 1，逐级连乘）。
- **三重聚合**：按「物料号 + 发运主体 + 发运方式 + 备注」合并求和——同一物料在不同父节点下，只要发运配置相同，数量自动汇总。
- **总重**：按各行"数量 × 净重"逐行求和。
- **导出**：📊 导出Excel（带分组、边框、项目总重的格式化表格）或 📄 导出CSV（UTF-8-BOM 编码，Excel 可直接打开不乱码）。

## 九、常见问题（操作向）

**Q：导入后某些节点没进发运单？**
A：只有"是否展开=否 且 配齐发运主体+方式"的绿色节点才进发运单。检查该节点是否为展开节点（白色）或边界节点（浅黄、未配齐）。

**Q：想让某个物料单独发运？**
A：把它的"是否展开"设为"否"，再指定发运主体和发运方式即可（选 98/99 会自动配方式）。

**Q：一个物料要拆成两批发运？**
A：右键该节点 → ✂️ 拆分物料，分别输入数量、发运主体和方式。

**Q：CSV 导入报错或乱码？**
A：程序已自动尝试 UTF-8 / GBK / GB18030 编码。仍失败请确认文件确为 ERP 导出的 BOM 文件，且含"子物料号、父物料号、数量、子物料净重"等必需列。

**Q：发运主体名称想自定义？**
A：点工具栏 🏷️ 发运主体，在定义窗口增删改名称，或用预设管理（保存为预设 / 新建 / 置为当前）。
