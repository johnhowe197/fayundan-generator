### 3.2 优点

1. **模块化设计优秀** — Mixin 拆分后，main_window.py 从 3881 行降至 700 行
2. **数据层独立** — EntityConfigManager 和 ProgressFileManager 职责清晰
3. **调用方式不变** — Mixin 模式保持了原有代码的调用方式
4. **配置统一** — 发运主体映射单一数据源，避免不一致
5. **撤销/恢复可靠** — 复合 key 解决了同物料多实例的冲突问题
6. **BOMNode 计算安全** — 避免了创建时的错误计算
